папка contact_form - шаблон для компонента form.result.new для 1с Битрикс. Управление сайтом. Бизнес.

УСТАНОВКА:

Для того, чтобы добавить данный шаблон в структуру, нужно скопировать папку contact_form в папку компонентов сайта:
<корень_сайта>/local/templates/.default/components/bitrix/form.result.new/contact_form/

Если данных папок нет в структуре сайта, то создайте в соотсветвии с путём выше. 

ПРИМЕНЕНИЕ:
1. открыть страницу администрирования->перейти в "сервисы"-> настройка форм
2. Создать форму, добавить 5 вопросов:Ваше имя, Компания/должность, Email, Номер телефона, сообщение
3. у всех вопросов, кроме "сообщение" указать обязательное заполнение, у Email указатьтипо поля "email", у "сообщение - "textarea"
4. Перейти на сайт, открыть страницу, на которую будет добавляться форма, перейти в режим редактирования страницы
5. добавить форму на сайт (сервисы->веб-формы->заполнение выб-формы)
6. перейти в параметры компонента и изменить: шаблон компонента на "contact_form", ID формы - "ВАШЕ ID созданной ранее веб формы"
При верных настройках на странице появится веб-форма как на приложенном изображении "шаблон компонента form.result.new.jpg"
